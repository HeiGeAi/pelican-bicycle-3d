# 《末班车：下班生还》美术制作说明

版本：v0.2。2026-09-23。

## 目标与一致性

用户给出的截图只用来判断中央载具、两侧来敌和移动端竖屏阅读关系，不提取或复刻其中的角色、图标和界面。本站既有原创封面仅作为新资源的色调与世界观参考。

统一采用暖赭石沙地、锈橙金属、炭黑阴影和克制的青色灯光。战场为严格俯视角，人物为略带俯视的正面三分之四视角。原图故意保留可辨识的大像素色块，显示时关闭 Canvas 平滑。角色应在 35 至 64 个游戏像素的尺寸下仍能区分。

## 生成与选用

全部资源使用内置 `image_gen` 文生图或编辑模式生成。`art/source/` 保存选用的原始 PNG；`art/game/` 保存实际加载的 WebP。封面 `cover.webp` 在首版生成，此轮用于开场和风格参考。人物图实际有原生 alpha 通道，无须抠图。

| 发布文件 | 主体与提示词要点 | 战场用途 |
| --- | --- | --- |
| `battlefield.webp` | 480×720 竖屏俯视战场。中央连续双轨，左右废城沙地，无车无人无字 | 全屏底图 |
| `train.webp` | 俯视橙色装甲通勤车，车头朝上，2 列 3 行共 6 个屋顶格位，无人无字 | 可部署载具 |
| `guard.webp` | 深色帽与橙色反光背心，青灯短枪，完整人物 | 安保 |
| `sniper.webp` | 金发档案员、肩包与远距枪，完整人物 | 档案员 |
| `barista.webp` | 红围巾、围裙、咖啡压力罐与蒸汽喷头 | 咖啡师 |
| `mechanic.webp` | 青色护目镜、蓝灰工装、扳手与维修箱 | 维修员 |
| `walker.webp` | 灰绿皮肤、破损办公室衬衫与领带 | 普通感染者 |
| `runner.webp` | 芥末色快递衣与斜挎包，前倾奔跑 | 快速感染者 |
| `brute.webp` | 破工地帽与方形金属胸甲 | 重甲感染者 |
| `boss.webp` | 酒红色破大衣、领带、金属公文箱护臂 | 巨型感染主管 |

共通负面约束：不画 UI、文字、徽章、Logo、水印、血腥或地面投影，不引入紫色装饰。人物与车必须完整可见、轮廓清楚、背景透明。生成时输入的封面是风格参考，不沿用其构图与角色。

## 游戏接入

运行时图像总量约 684 KB。`src/game.js` 会预加载 10 张 WebP；完成后才允许开始游戏。任一资源加载失败时，沿用程序绘制的备用画面并在开场文案中明确提示。车体六格与引擎 `SLOTS` 坐标一致，格位交互仍是语义按钮，图片没有取代可访问的文字与反馈。

后续替换素材时必须核对：六格和点击区域对齐、敌人从左右两侧出现、角色在手机尺寸可辨认、招募卡与战场角色一致、首屏加载可结束、浏览器控制台无资源错误、低性能设备没有明显掉帧。
